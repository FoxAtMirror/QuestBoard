# QuestBoard — журнал квестов в стиле World of Warcraft

Небольшое мультиплатформенное приложение (Windows / macOS / Linux), которое превращает
список задач в журнал квестов: окно без системной рамки, прижатое к правому краю экрана,
всегда поверх других окон, с оформлением в духе игрового журнала заданий.

Задачи добавляются локально: кнопка **«Выдать квест»** в самом приложении.
Удалённая выдача квестов с другого устройства заложена в код, но по умолчанию выключена
(см. [Дорожная карта](docs/ROADMAP.md)).

> Оформление сделано «в духе» WoW собственными CSS/SVG-элементами: файлы Blizzard не
> используются и не копируются. Шрифты — открытые Cinzel и Spectral (лицензия OFL).

## Поведение окна: не окно, а дополнение рабочего стола

Журнал сделан по образцу игрового интерфейса, а не обычного приложения:

- **нет кнопки на панели задач и нет пункта в Alt+Tab** — окно создаётся как служебное (`toolbar` / `panel`);
- **не перехватывает фокус** — появляется через `showInactive`, активная программа не теряет фокус;
- **виден поверх полноэкранных игр** — уровень `screen-saver`, работает и в режиме «поверх окон»;
- **на всех рабочих столах** — виден на каждом виртуальном рабочем столе;
- **сквозные клики** — окно не мешает работе, у левого края есть горячая зона, где журнал оживает;
- **глобальные хоткеи** — `Ctrl+Alt+Q` показать/скрыть журнал, `Ctrl+Alt+N` сразу создать квест;
- **два слоя** (переключается в настройках и в трее):
  - *Поверх окон* — как игровой оверлей, поверх всего;
  - *На рабочем столе* — поверх обоев, но под обычными окнами (как виджет рабочего стола).

## Возможности

- **Журнал квестов** — три вкладки: Журнал (активные), Цели (задачи с чек-листами), Выполнено.
- **Принятие квеста как в WoW** — новая задача (из формы, с другого устройства или по хоткею)
  появляется отдельным окном по центру экрана: золотое название, описание, цели, награда
  и кнопки **Принять** / **Отказаться**. В журнал квест попадает только после принятия.
- **Режим «только текст»** (по умолчанию) — на экране висят только строки заданий: без рамки,
  без панели, без разделителей, как парящий текст в игре. Управление (шапка, вкладки, поиск,
  рамка героя) проявляется, когда подводишь курсор.
- **Виджет-оверлей** — прозрачное окно поверх всего, прижатое к краю экрана.
  Режимы фона: только текст, прозрачный (с золотой рамкой), полупрозрачная панель, сплошной.
- **Сквозные клики** — окно можно «пропустить насквозь», чтобы не мешало работе;
  у левого края остаётся горячая зона, где окно снова оживает.
- **Цели и награды** — у квеста есть цели, награда, дедлайн, важность, зона-проект и «кто выдал».
- **Опыт и уровень героя** — за выполнение квеста начисляется опыт, растёт уровень (внизу рамка героя).
- **Звуки** — короткие фанфары, синтезированные на лету (Web Audio), без внешних файлов.
- **Трекер** — нижний блок с активными квестами и прогрессом, как quest tracker в игре.
- **Данные локальные** — один JSON-файл в папке данных приложения, никаких аккаунтов и сети.

## Выдача квестов с другого устройства

Внутри приложения поднят локальный сервер выдачи. Человек с другого ПК или телефона
открывает ссылку (или сканирует QR) и выдаёт тебе задачу — она сразу появляется в журнале
с пометкой, что выдана удалённо.

Кнопка **⇄** в панели журнала открывает панель выдачи:

- **ссылка** вида `http://<твой-IP>:7788/?code=XXXXXX` и **QR-код** с этой ссылкой;
- **код доступа** — 6 символов, можно скопировать или перевыпустить (⟳);
- **вкл/выкл сервера**, порт и режим «требовать код»;
- кнопка «Открыть страницу выдачи у себя».

Как это работает:

1. Ты (или коллега) открываешь ссылку на том же Wi-Fi — или на телефоне сканируешь QR.
2. Вводишь код доступа и заполняешь форму: название, описание, кто выдал, важность,
   уровень, зона, награда, цели.
3. У тебя на экране появляется окно «Принять квест» — как в WoW: название, цели, награда.
4. **Принять** — квест уходит в журнал (отмечен как активный). **Отказаться** — квест отбрасывается.

Защита: без верного кода сервер отвечает `401` — выдача невозможна.
Код хранится в `%APPDATA%/QuestBoard/access-code.txt` и переживает перезапуск.

**Доступ из интернета.** Локальный адрес работает только внутри твоей сети. Чтобы выдавать
квесты извне, пробрасывай порт через туннель:

```bash
cloudflared tunnel --url http://localhost:7788
# или
ngrok http 7788
```

Полученный публичный адрес раздаёшь тем, кто выдаёт квесты (код доступа всё равно нужен).

## Быстрый старт

```bash
npm install        # установка зависимостей
npm run dev        # запуск в режиме разработки (Vite + Electron)
```

Продакшен-сборка и запуск собранного приложения:

```bash
npm run build      # renderer (Vite) + main/preload (esbuild)
npm start          # запуск собранного приложения
```

Предпросмотр интерфейса в обычном браузере (без Electron, с демо-данными):

```bash
npm run dev:renderer    # http://localhost:5173
```

Автотест механики квестов (создание → цели → выполнение → опыт):

```bash
QUESTBOARD_SELFTEST=1 npx electron .
```

Снимок окна для визуальной проверки:

```bash
QUESTBOARD_SHOT=shot.png npx electron .
```

Дистрибутивы под все платформы:

```bash
npm run dist:win     # .exe (NSIS-установщик)
npm run dist:mac     # .dmg
npm run dist:linux   # AppImage + .deb
npm run dist         # все цели сразу
```

Результат попадает в папку `release/`.

> Если сборка падает с `EBUSY: ... app.asar` — это Windows держит файл (антивирус,
> индексатор, файловый watcher). Обход: `npm run dist:win:alt` собирает в `release-new`,
> затем `npm run release:sync` переносит свежие файлы в `release/`.

## Как пользоваться

| Действие | Как |
| --- | --- |
| Создать квест | Кнопка **«Выдать квест»** (вверху журнала или `+` в рамке героя) |
| Взять в работу | На квесте → **«В работу»** |
| Закрыть цель | Клик по цели в списке (галочка ставится сама, всё закрытое — квест выполнен) |
| Выполнить квест | Кнопка **«Выполнен»** или клик по названию квеста |
| Настроить вид | Кнопка **⚙** — фон, прозрачность, сквозные клики, сторона экрана, высота, звуки, автозапуск, герой |
| Скрыть окно | `—` в шапке; вернуть — значок в трее (правый клик → «Показать / скрыть журнал») |
| Изменить размер | Потянуть нижний левый уголок окна |

## Структура проекта

```
questboard/
├── shared/types.ts        # общие типы (квест, игрок, настройки)
├── src/main/              # процесс Electron
│   ├── main.ts            # точка входа, IPC, трей, автозапуск
│   ├── window.ts          # прозрачное окно-оверлей, привязка к краю
│   ├── store.ts           # хранение квестов (JSON, атомарная запись)
│   └── server.ts          # сервер выдачи квестов (выключен по умолчанию)
├── src/preload/           # безопасный мост main → renderer
├── src/renderer/          # интерфейс журнала (React + CSS)
│   ├── App.tsx
│   ├── components/        # карточка квеста, формы, настройки, тосты
│   └── styles.css         # всё оформление
├── scripts/               # сборка main-процессов и генерация иконок
└── electron-builder.yml   # конфиг дистрибутивов win/mac/linux
```

## Где лежат данные

`%APPDATA%/QuestBoard` (Windows), `~/Library/Application Support/QuestBoard` (macOS),
`~/.config/QuestBoard` (Linux):

- `questboard.json` — квесты, герой и настройки;
- `quests-live.json` — зеркало списка квестов (его можно читать извне — например, будущим аддоном для WoW).

Кнопка «Папка данных» в настройках открывает эту директорию.
